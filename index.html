بخش اول

۱. NumPy چیه و به چه درد می‌خوره؟

اسمش از Numerical Python میاد. مهم‌ترین ابزارش آرایه‌ای به اسم ndarray هست. آرایه رو مثل یه ردیف یا جدول از مقدارها تصور کن. NumPy کمک می‌کنه بدون اینکه برای تک‌تک عددها حلقه بنویسی، عملیات رو روی همه‌شون انجام بدی.

چرا به‌جای لیست پایتون از NumPy استفاده کنیم؟

# با لیست معمولی باید روی اعضا حرکت کنیم
scores = [12, 15, 18]
new_scores = []
for score in scores:
    new_scores.append(score + 2)
print(new_scores)  # [14, 17, 20]

# با NumPy عملیات رو مستقیم روی کل آرایه انجام می‌دیم
import numpy as np
scores_array = np.array([12, 15, 18])
print(scores_array + 2)  # [14 17 20]

یه نکته مهم: عملگر + برای لیست و آرایه رفتار یکسانی نداره. برای لیست، اضافه‌کردن یک عدد به لیست به این شکل مجاز نیست؛ اما np.array + 2 عدد ۲ رو به تک‌تک اعضا اضافه می‌کنه.

کجاها استفاده می‌شه؟

  • محاسبه میانگین، جمع، کمینه و بیشینه
  • آمار و تحلیل داده و شبیه‌سازی
  • کار با ماتریس‌ها و عملیات جبر خطی
  • آماده‌سازی داده‌های عددی برای یادگیری ماشین
  • کار با آرایه‌های تصویر و سیگنال

۲. ساخت آرایه‌ها

آرایه یک‌بعدی

import numpy as np

scores = np.array([17, 19, 14, 20])
print(scores)
print(scores.ndim)   # تعداد بُعدها: 1
print(scores.shape)  # شکل آرایه: (4,)
print(scores.size)   # تعداد کل اعضا: 4
print(scores.dtype)  # نوع داده، مثلاً int64

آرایه دوبعدی؛ مثل جدول

scores = np.array([
    [17, 19, 14],
    [20, 16, 18]
])
print(scores.shape)  # (2, 3): دو ردیف، سه ستون
print(scores.ndim)   # 2

آرایه دوبعدی بالا دو ردیف داره؛ هر ردیف می‌تونه نمره‌های یک نفر یا یک گروه رو نگه داره. در آرایه‌های معمول NumPy، اعضا عموماً نوع داده یکسانی دارن.

تابع‌های ساخت آرایه که زیاد به کار میان

کدچی می‌سازه؟نمونه نتیجه
np.array([2, 4])از داده موجود آرایه می‌سازه[2, 4]
np.zeros(4)چهار تا صفر[0., 0., 0., 0.]
np.ones(3)سه تا یک[1., 1., 1.]
np.arange(1, 6)از ۱ تا قبل از ۶[1, 2, 3, 4, 5]
np.linspace(0, 1, 5)پنج عدد با فاصله مساوی بین دو سر بازه[0., .25, .5, .75, 1.]
np.full(3, 7)سه بار مقدار ۷[7, 7, 7]
تمرین کوتاه ۱

یه آرایه از عددهای ۵ تا ۱۵ بساز. بعد تعداد اعضا و شکلش رو چاپ کن.

numbers = np.arange(5, 16)
print(numbers)
print(numbers.size)   # 11
print(numbers.shape)  # (11,)

۳. عملیات ریاضی و آمار در NumPy

تصور کن هر عدد میزان فروش یک روزه. می‌خوای به همه روزها ۱۰ واحد اضافه کنی یا میانگین فروش رو دربیاری. اینجا NumPy حسابی می‌درخشه.

sales = np.array([10, 20, 30, 40])

print(sales + 5)       # [15 25 35 45]
print(sales * 2)       # [20 40 60 80]
print(sales / 10)      # [1. 2. 3. 4.]
print(sales.sum())     # 100
print(sales.mean())    # 25.0
print(sales.min())     # 10
print(sales.max())     # 40
print(np.median(sales))# 25.0
print(sales.std())     # انحراف معیار
حواست باشه: sales * 2 هر عضو رو دو برابر می‌کنه، نه اینکه آرایه رو دو بار پشت‌سرهم تکرار کنه. این رفتار «عنصر به عنصر» (element-wise) نام داره.

مقایسه دو آرایه

a = np.array([10, 20, 30])
b = np.array([1,  2,  3])

print(a + b)  # [11 22 33]
print(a * b)  # [10 40 90]

آرایه دوبعدی و axis

scores = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

print(scores.sum())          # 210؛ جمع کل
print(scores.sum(axis=0))    # [50 70 90]؛ جمع هر ستون
print(scores.sum(axis=1))    # [60 150]؛ جمع هر ردیف
print(scores.mean(axis=1))   # [20. 50.]؛ میانگین هر ردیف

ترفند حفظی: در آرایه دوبعدی، axis=0 یعنی در امتداد ردیف‌ها جمع می‌زنیم و برای هر ستون نتیجه می‌گیریم؛ axis=1 یعنی در امتداد ستون‌های هر ردیف جمع می‌زنیم.

مرتب‌سازی و پیدا کردن جایگاه

numbers = np.array([7, 2, 9, 4])
print(np.sort(numbers))      # [2 4 7 9]
print(np.argmax(numbers))    # 2؛ جایگاه بزرگ‌ترین عضو
print(np.argmin(numbers))    # 1؛ جایگاه کوچک‌ترین عضو

اینجا جایگاه‌ها از صفر شروع می‌شن؛ پس بزرگ‌ترین عدد یعنی ۹ در اندیس ۲ قرار داره.

۴. انتخاب اعضا، فیلترکردن و تغییر شکل

اندیس و برش (slicing)

numbers = np.array([10, 20, 30, 40, 50])
print(numbers[0])     # 10؛ عضو اول
print(numbers[-1])    # 50؛ عضو آخر
print(numbers[1:4])   # [20 30 40]؛ اندیس ۱ تا قبل از ۴
print(numbers[::2])   # [10 30 50]؛ یکی درمیون

انتخاب با شرط

scores = np.array([12, 18, 9, 20, 15])
passed = scores >= 15
print(passed)         # [False True False True True]
print(scores[passed]) # [18 20 15]
print(scores[scores >= 15])

reshape یعنی تغییر شکل

numbers = np.arange(1, 7)
matrix = numbers.reshape(2, 3)
print(matrix)
# [[1 2 3]
#  [4 5 6]]

تعداد کل خانه‌ها باید ثابت بمونه؛ نمی‌شه ۶ عدد رو به شکل ۴ ردیف و ۲ ستون درآورد، چون ۸ خانه لازم می‌شه.

ترکیب آرایه‌ها

a = np.array([1, 2])
b = np.array([3, 4])
print(np.concatenate([a, b]))  # [1 2 3 4]
تمرین کوتاه ۲

از آرایه [4, 11, 8, 17, 20, 3] فقط عددهای بزرگ‌تر از ۱۰ رو جدا کن و بعد آرایه رو به شکل ۲ ردیف و ۳ ستون دربیار.

x = np.array([4, 11, 8, 17, 20, 3])
print(x[x > 10])  # [11 17 20]
print(x.reshape(2, 3))

۵. عدد تصادفی و انتخاب شرطی

برای شبیه‌سازی پرتاب تاس، ساخت داده آزمایشی یا تست‌کردن ایده‌ها می‌تونیم عدد تصادفی بسازیم. برای اینکه نتیجه هر بار قابل تکرار باشه، از seed استفاده می‌کنیم.

rng = np.random.default_rng(42)
dice = rng.integers(1, 7, size=10)  # ده عدد از ۱ تا ۶
print(dice)
print(np.unique(dice))              # مقدارهای یکتای مشاهده‌شده

عدد ۷ در integers(1, 7) وارد بازه نمی‌شه؛ حد بالای این تابع در این مثال شامل نمی‌شه.

where؛ اگر این شرط درست بود...

scores = np.array([8, 12, 17, 9])
labels = np.where(scores >= 10, "قبول", "نیاز به تمرین")
print(labels)

چند تابع کاربردی دیگه

تابعکاربرد

np.sqrt(x)ریشه دوم
np.unique(x)مقدارهای یکتا
np.where(condition, a, b)انتخاب مقدار بر اساس شرط
np.clip(x, low, high)محدودکردن مقدارها به بازه مشخص

np.percentile(x, 50)صدک ۵۰؛ معادل میانه در تعریف معمول

۶. Pandas چیه؟

Pandas کتابخونه‌ای برای کار با داده‌های جدولی و سری‌های داده است. اگه داده‌هات توی فایل CSV، اکسل یا خروجی دیتابیس باشن، Pandas می‌تونه خوندن، بررسی، تمیزکاری، فیلتر، تحلیل و ذخیره‌کردنشون رو راحت کنه.

Series

مثل یک ستون از داده‌هاست؛ مثلاً فقط نمره‌ها یا فقط اسم‌ها.

import pandas as pd
scores = pd.Series([17, 19, 14])
print(scores)

DataFrame

مثل یک جدول کامل با چند ردیف و چند ستون.

df = pd.DataFrame({
    "name": ["آوا", "پارسا"],
    "score": [18, 16]
})
print(df)

برای راحتی، معمولاً Pandas رو با اسم کوتاه pd وارد می‌کنیم. NumPy هم معمولاً با np شناخته می‌شه.

۷. ساخت جدول و دیدن اطلاعاتش

بیایم یه جدول کوچیک از دانش‌آموزها بسازیم و ازش برای مثال‌های بعدی استفاده کنیم.

import pandas as pd
import numpy as np

df = pd.DataFrame({
    "name": ["آوا", "پارسا", "رها", "کیان", "آوا"],
    "city": ["تهران", "تبریز", "تهران", "شیراز", "تهران"],
    "score": [18, 15, 20, np.nan, 18],
    "hours": [4, 2, 5, 1, 4]
})

print(df.head())       # پنج ردیف اول
print(df.shape)        # تعداد ردیف و ستون
print(df.columns)      # نام ستون‌ها
print(df.dtypes)       # نوع داده هر ستون
print(df.info())       # خلاصه ساختار جدول
print(df.describe())   # آمار ستون‌های عددی
یه نکته: np.nan یعنی مقدار عددی موجود نیست یا گم شده. در دنیای واقعی ممکنه دانش‌آموز نمره نداده باشه یا اطلاعات به‌درستی ثبت نشده باشه.

انتخاب ستون و ردیف

print(df["name"])               # یک ستون؛ خروجی Series
print(df[["name", "score"]])    # دو ستون؛ خروجی DataFrame
print(df.iloc[0])                # ردیف اول بر اساس جایگاه
print(df.loc[0, "name"])         # مقدار ستون name در برچسب ردیف ۰

iloc با جایگاه عددی کار می‌کنه. loc با برچسب ردیف و نام ستون. وقتی اندیس پیش‌فرض رو تغییر بدی، این فرق مهم می‌شه.

فیلتر کردن ردیف‌ها

print(df[df["score"] >= 18])       # نمره ۱۸ یا بیشتر
print(df[df["city"] == "تهران"])   # فقط تهران
print(df[(df["score"] >= 18) & (df["hours"] >= 4)])
print(df[df["city"].isin(["تهران", "تبریز"])])

برای ترکیب شرط‌ها در Pandas از & برای «و» و | برای «یا» استفاده می‌کنیم و هر شرط رو داخل پرانتز می‌ذاریم. از and و or معمولی برای این فیلترها استفاده نکن.

ساختن ستون جدید

df["score_plus_one"] = df["score"] + 1
df["passed"] = df["score"] >= 10
print(df[["name", "score", "score_plus_one", "passed"]])

محاسبه روی یک ستون معمولاً برای همه ردیف‌ها انجام می‌شه؛ لازم نیست دستی روی تک‌تک ردیف‌ها حلقه بزنی.

مرتب‌سازی و انتخاب چند ردیف

print(df.sort_values("score", ascending=False))
print(df.sort_values(["city", "score"]))
print(df.nlargest(3, "score"))   # سه نمره بزرگ؛ ردیف‌های دارای مقدار گمشده معمولاً انتخاب نمی‌شن

۸. تمیزکاری داده‌ها (Data Cleaning)

داده واقعی معمولاً بی‌نقص نیست: بعضی خانه‌ها خالی‌ان، اسم‌ها چند جور نوشته شدن، ردیف تکراری داریم یا عددها اشتباهی به شکل متن ذخیره شدن. قبل از نتیجه‌گیری باید این موارد رو بررسی کنیم.

پیدا کردن داده‌های خالی

print(df.isna())             # برای هر خانه: خالی هست یا نه؟
print(df.isna().sum())       # تعداد مقدارهای خالی هر ستون
print(df["score"].isna())    # فقط ستون نمره

جایگزین کردن یا حذف مقدارهای خالی

# جایگزینی مقدار خالی نمره با میانگین نمره‌ها
df["score_filled"] = df["score"].fillna(df["score"].mean())

# حذف ردیف‌هایی که score آن‌ها خالی است (فقط روی خروجی)
without_missing = df.dropna(subset=["score"])

# نکته: fillna و dropna را آگاهانه انتخاب کن؛
# پرکردن با میانگین همیشه تصمیم درستی نیست.

تکراری‌ها و متن‌ها

print(df.duplicated())                 # ردیف‌های تکراری کامل
print(df.drop_duplicates())             # حذف ردیف‌های کاملاً تکراری
print(df["name"].str.strip())           # حذف فاصله از ابتدا و انتهای متن
print(df["name"].str.lower())           # حروف انگلیسی را کوچک می‌کند
print(df["city"].value_counts())        # تعداد هر شهر

برای متن فارسی، lower() معمولاً کاربردی برای حروف فارسی نداره، اما برای متن انگلیسی مفیده. پاک‌سازی متن فارسی ممکنه به یکسان‌سازی «ی/ي»، «ک/ك» و فاصله‌ها هم نیاز داشته باشه.

تبدیل نوع داده

raw = pd.DataFrame({"score": ["18", "15", "نامشخص"]})
raw["score_num"] = pd.to_numeric(raw["score"], errors="coerce")
print(raw)

با errors="coerce" مقدارهایی که به عدد تبدیل نمی‌شن به مقدار گمشده تبدیل می‌شن تا بتونیم بعداً بررسی‌شون کنیم؛ این کار نباید باعث بشه بدون بررسی، داده مهمی رو نادیده بگیریم.

۹. آمار، گروه‌بندی و تحلیل داده

فرض کن مدیر مدرسه می‌پرسه: «میانگین نمره هر شهر چقدره؟» یا «چند دانش‌آموز از هر شهر داریم؟» لازم نیست دستی بشمری؛ از گروه‌بندی استفاده کن.

print(df["score"].mean())      # میانگین؛ مقدارهای گمشده پیش‌فرض نادیده گرفته می‌شن
print(df["score"].median())    # میانه
print(df["score"].min())
print(df["score"].max())
print(df["score"].sum())
print(df["city"].value_counts())

# میانگین نمره در هر شهر
print(df.groupby("city")["score"].mean())

# چند آمار به‌صورت همزمان
summary = df.groupby("city").agg(
    average_score=("score", "mean"),
    highest_score=("score", "max"),
    student_count=("name", "count")
)
print(summary)

ایده groupby اینه: اول داده‌ها رو به گروه‌های جدا تقسیم می‌کنیم، بعد روی هر گروه محاسبه انجام می‌دیم و در آخر نتیجه‌ها رو کنار هم می‌ذاریم.

جدول محوری (Pivot Table)

# میانگین نمره هر شهر؛ خروجی به شکل جدول خلاصه
pivot = pd.pivot_table(
    df,
    values="score",
    index="city",
    aggfunc="mean"
)
print(pivot)

۱۰. خواندن و ذخیره فایل‌ها + ترکیب جدول‌ها

خواندن و ذخیره کردن

# فایل باید در مسیر قابل دسترس محیط پایتون باشه
data = pd.read_csv("students.csv")

index=False یعنی شماره ردیف Pandas رو به‌عنوان یک ستون اضافه در فایل ذخیره نکن.

ترکیب جدول‌ها مثل JOIN در SQL

students = pd.DataFrame({
    "student_id": [1, 2, 3],
    "name": ["آوا", "پارسا", "رها"]
})
results = pd.DataFrame({
    "student_id": [1, 3],
    "score": [18, 20]
})

combined = students.merge(results, on="student_id", how="left")
print(combined)

how="inner"فقط کلیدهایی که در هر دو جدول وجود دارن
how="left"همه ردیف‌های جدول سمت چپ؛ اطلاعات متناظر از جدول راست اضافه می‌شه
how="right"همه ردیف‌های جدول سمت راست
how="outer"همه کلیدهای هر دو جدول؛ جاهای بدون تطبیق خالی می‌مونن

۱۲. تمرین‌های خودت رو حل کن 💪

اول خودت فکر کن؛ بعد دکمه راه‌حل رو بزن. بهتره کد رو واقعاً در محیط پایتون اجرا کنی.

تمرین ۱ — NumPy | سطح آسون

آرایه نمره‌ها اینه: [12, 18, 16, 9, 20, 14]. میانگین، کمترین و بیشترین نمره رو چاپ کن.

scores = np.array([12, 18, 16, 9, 20, 14])
print(scores.mean())
print(scores.min())
print(scores.max())
تمرین ۲ — NumPy | سطح متوسط

از همون آرایه، نمره‌های ۱۵ یا بیشتر رو جدا کن و جایگاه نمره بیشینه رو پیدا کن.

print(scores[scores >= 15])

تمرین ۳ — Pandas | سطح آسون

جدولی با ستون‌های name و score برای سه نفر بساز. بعد فقط ردیف‌های نمره بالای ۱۵ رو نمایش بده.

تمرین ۴ — Pandas | تمیزکاری

یه ستون قیمت با مقادیر [100, None, 300, 200] بساز. مقدار خالی رو پیدا کن و تعداد مقدارهای خالی رو حساب کن.

prices = pd.DataFrame({"price": [100, None, 300, 200]})

تمرین ۵ — Pandas | گروه‌بندی

جدولی از شهر و فروش بساز و مجموع فروش هر شهر رو حساب کن.

sales = pd.DataFrame({

print(sales.groupby("city")["amount"].sum())

۱۳. مینی‌پروژه: تحلیل فروش یک فروشگاه 🛍️

حالا فرض کن یه فروشگاه کوچیک بهت داده‌هاش رو داده و می‌خواد بفهمه چه محصولی درآمد بیشتری داشته. این پروژه رو قدم‌به‌قدم انجام بده.

import pandas as pd
import numpy as np

shop = pd.DataFrame({
    "product": ["دفتر", "خودکار", "دفتر", "مداد", "خودکار", "مداد"],
    "category": ["تحریر", "تحریر", "تحریر", "تحریر", "تحریر", "تحریر"],
    "price": [50000, 20000, 50000, 10000, 20000, 10000],
    "quantity": [3, 10, 2, 20, 5, 10]
})

# ۱) درآمد هر ردیف رو بساز
shop["revenue"] = shop["price"] * shop["quantity"]

# ۲) اطلاعات رو ببین و خلاصه بگیر
print(shop.head())
print(shop.describe())

# ۳) درآمد کل هر محصول
by_product = shop.groupby("product")["revenue"].sum()
print(by_product)

# ۴) محصول با بیشترین درآمد
print(by_product.idxmax())

# ۵) ذخیره گزارش
shop.to_csv("shop_report.csv", index=False)

چالش‌های اضافه

  • محصول‌ها رو از بیشترین درآمد به کمترین مرتب کن.
  • میانگین تعداد فروش هر محصول رو به‌دست بیار.
  • قیمت یکی از ردیف‌ها رو خالی کن و راهی برای مدیریت مقدار خالی پیشنهاد بده.
  • یک ستون تخفیف اضافه کن و درآمد بعد از تخفیف رو حساب کن.
  • در دو جمله توضیح بده کدوم محصول بهتر فروخته و چرا؛ فقط به تعداد نگاه نکن، درآمد رو هم بررسی کن.
